# BORDERFALL

A touch-first autonomous war sandbox for GitHub Pages.

## Upload
Upload every file in this ZIP directly to the root of a GitHub repository. There are no folders.
Then enable GitHub Pages from the repository settings and select the main branch/root.

## Features
- Procedural worlds and multiple scenarios
- AI nations, expansion, diplomacy, alliances, war, peace, rebellions and collapse
- Economy, army, technology, stability, casualties and national history
- God Mode intervention tools
- Save/load plus JSON export/import
- Touch pan/zoom and desktop mouse controls
- Procedural sound effects and music with 0-2000% volume controls
- Installable PWA with iPhone/iPad home-screen support
- Simulated multiplayer observer lobby with AI chat
- Private room codes of 5+ characters stay empty by design

No external assets or libraries are required.
